# Homebrew tap for bige-ops

This tap installs the public macOS build of [bige-ops](https://bige.dev/), a
desktop application for simulating, deploying, and operating cloud stacks.

## Install

```bash
brew tap simondelamarre/bige-ops
brew install --cask bige-ops
```

The current cask targets Apple Silicon and requires macOS Sonoma or newer.

## Update

```bash
brew update
brew upgrade --cask bige-ops
```

## Uninstall

```bash
brew uninstall --cask bige-ops
```
